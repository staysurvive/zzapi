# Integration QA Screen Contract

The route/surface manifest is the source list. Each phase contributes its own screen contract; Phase 6 adds no new implementation owner. For each row, the final evidence record must include route/section, role, state, locale, theme, CSS viewport, captured pixel size, fixture, console, screenshot path and audit result.

Required state classes: populated, loading, empty, error, permission-denied, disabled, hover/focus/active and mutation-pending where applicable.
